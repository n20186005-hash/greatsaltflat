# Verification scope

Run the frozen install, Astro check and SSR build. Inspect the emitted server entry, six prerendered policy/settings pages, sitemap, assets, image licence records and private-data scan.

Homepages retain runtime server weather, so an empty static home directory is not proof of route coverage. Native SSR HTTP behavior, weather success/failure, browser geometry and interactions, remote activation and required-domain production checks remain separate gates.
